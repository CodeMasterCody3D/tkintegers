# Tk-Integers project instructions

- Preserve the original Tk-Integer container modules and source model files.
- Model Atlas is the **entire original qwen-atlas HTML app embedded in a tab**,
  including its flow diagram and explanations. Never replace it with a native
  imitation or a reduced table-based UI.
- Keep the tab name Model Atlas. The button beside the HTML import button exports
  and loads the recipe into Tk-Integers for review; it never auto-starts conversion.
- Refer to PROJECT.md and BOARD.md for implementation and verification status.
